# 威廉斯創造力傾向量表｜評分方法與構面指標

## 評分方法摘要
- 本量表為王木榮修訂版本，共 50 題，涵蓋冒險性、好奇性、想像力、挑戰性四大構面。
- 受測者依題項描述勾選程度後，依構面題項加總並換算常模分數。
- 四大構面相互補充，可對學童或學習者的創造力傾向進行初步定性分析。

## 構面指標彙整

### 好奇性（Curiosity）
1. 富有追根究柢的精神，經常主動問「為什麼」。
2. 主意多、樂於接觸曖昧或尚未釐清的情境。
3. 願意深入思索事物的奧妙，從多角度檢視答案。
4. 能把握特殊現象、觀察結果並比較差異。
5. 做功課時喜歡參考不同資料，玩猜謎或拆解玩具來理解原理。

### 想像力（Imagination）
1. 能視覺化並建立心像，用畫面理解概念。
2. 樂於幻想尚未發生過的事情，補完故事或結局。
3. 直覺地推測情節，敢於描繪超越現實的構想。
4. 能突破感官或現實限制，將自己代入不同角色或時空。

### 挑戰性（Challenge）
1. 不斷尋找各種可能性，質疑慣例並嘗試新方法。
2. 了解理想與現實的差距，規畫縮短差距的策略。
3. 能夠從雜亂訊息中理出秩序，整合多元觀點。
4. 願意探究複雜問題並主動注意細節或潛在風險。

### 冒險性（Risk Taking）
1. 勇於面對失敗或批評，把挫折視為學習。
2. 敢於猜測結果，在未知情境中仍願意試驗。
3. 能在雜亂或限制多的環境下完成任務。
4. 為一己觀點辯護，願意在公開場合分享新構想。
